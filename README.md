# 💰 금고 털이 작전 — 부스 운영 프로그램

야탑제 심리탐구 동아리 부스용 웹 프로그램입니다.
두 명이 금고를 털고, 형사에게 체포되고, 각자 다른 조사실에서 수사관과 **채팅으로** 심문을 받은 뒤
**협력(입 다물기)** 또는 **배반(동료 불기)** 을 고르는 '죄수의 딜레마' 체험을 운영진이 관리합니다.

진행 단계: **대기 → 방탈출 → 체포 → 심문 → 판결 → 종료**

---

## 1. 준비물

- 서버용 노트북 1대 (Windows / Mac 모두 가능)
- 운영진 기기: 로비 매니저, 잡는 사람, 수사관(1~2명), 현황판(큰 화면)
- 조사실 태블릿(또는 폰) 2대: 용의자 A용, B용
- 모든 기기가 **같은 와이파이**(또는 같은 폰 핫스팟)에 연결

## 2. 설치 (처음 한 번만)

1. **Node.js 설치**: https://nodejs.org 에서 **LTS** 버전을 받아 설치합니다 (18 이상).
2. 이 폴더(`vault-heist`)를 노트북에 복사합니다.
3. 터미널(Windows는 "명령 프롬프트" 또는 PowerShell, Mac은 "터미널")을 열고 이 폴더로 이동합니다.
   ```
   cd 경로/vault-heist
   ```
4. 필요한 부품 설치 (인터넷 필요, 한 번만):
   ```
   npm install
   ```

## 3. 실행

```
npm start
```

켜지면 이렇게 주소가 나옵니다:

```
 이 노트북에서:  http://localhost:3000/staff
 다른 기기에서:  http://192.168.0.12:3000/staff   (Wi-Fi)
 로비 매니저:   http://192.168.0.12:3000/lobby
 ...
```

- 다른 기기에서는 **`http://192.168.x.x:3000`** 처럼 나온 주소를 씁니다 (`localhost`는 노트북에서만 됨).
- 끄려면 터미널에서 `Ctrl + C`. 다시 `npm start` 하면 **진행 상황·채팅·통계가 그대로 이어집니다** (`data/state.json`).
- 노트북이 잠자기 모드로 들어가지 않게 전원 설정을 바꿔 두세요.
- Windows에서 처음 실행할 때 방화벽 창이 뜨면 **"개인 네트워크 허용"** 을 눌러 주세요.

## 4. 역할별 화면 주소

| 역할 | 주소 | PIN |
|---|---|---|
| 운영진 화면 모음 (QR 포함) | `/staff` | 없음 |
| 🧾 로비 매니저 | `/lobby` | 필요 |
| 🚓 잡는 사람 | `/catcher` | 필요 |
| 🕵️ 수사관 | `/investigator` | 필요 |
| 📊 전체 현황판 (큰 화면) | `/board` | **없음** (채팅·참가 코드는 안 보임). 대기열이 크게 보이고, 팀마다 예상 대기 시간(약 N분)이 붙음 |
| 🔒 조사실 (용의자) | `/` (또는 `/s`) | 참가 코드 |

`/staff` 페이지를 열면 각 화면의 QR이 있어서, 운영진 기기로 찍기만 하면 됩니다.

## 5. 한 팀 진행 순서

1. **로비 매니저** `/lobby`: 팀 이름(또는 번호)과 참가자 이름(선택)을 넣고 **대기열에 추가**. ▲▼로 순서 변경, ✕로 삭제.
   - 팀마다 **조사실 코드 2개**(A용, B용)가 자동으로 만들어집니다. 🔑 버튼으로 QR을 볼 수 있어요.
2. 조사실 태블릿 A, B에서 QR을 찍거나 `/` 화면에 코드를 입력해 미리 연결해 둡니다.
   방탈출 동안 태블릿에는 "잠시 기다려 주세요"만 보여서 반전이 들키지 않습니다.
3. 팀이 입장하면 로비에서 **▶ 시작** → 단계가 **방탈출**로 바뀌고 타이머가 돕니다 (기본 3분 넘으면 빨간색).
4. 금고가 열리면 **잡는 사람** `/catcher`: 해당 팀의 **🚨 체포** → 팀 자루(1개)에 든 골드코인 수를 확인(−/+ 버튼, 기본 20) → **체포 확정**.
   - 코인 수는 **기록·현황판 표시용**이고, 보상(캔디)과는 관계없어요.
   - 두 조사실 기기가 연결돼 있으면 **바로 심문 단계**로 넘어가고, 형사의 첫 대사가 자동으로 두 조사실에 보내집니다.
   - 기기가 아직 안 붙어 있으면 **체포** 단계에서 기다리다가, 둘 다 연결되는 순간(또는 수사관/로비가 "심문 시작"을 누르면) 심문으로 넘어갑니다.
5. **수사관** `/investigator`: 위쪽에서 팀을 고르고, 맡을 용의자를 고릅니다.
   - 수사관 1명: **A+B 둘 다** (넓은 화면은 좌우로, 좁은 화면은 위아래로)
   - 수사관 2명: 한 명은 **A만**, 한 명은 **B만** (각자 자기 기기에서)
   - 압박 대사 버튼을 누르면 바로 보내집니다. 직접 입력도 가능.
   - 각 용의자가 **선택했는지만** 보이고, **무엇을** 골랐는지는 둘 다 고를 때까지 수사관에게도 안 보입니다.
6. 조사실의 용의자가 **협력 🤐 / 배반 🗣️** 중 하나를 눌러 확정합니다 (한 번 확정하면 못 바꿈).
7. 두 명이 모두 고르면 **판결**: 두 조사실 화면에 동시에 결과(서로의 선택, 받는 캔디 수)가 나오고, 수사관·로비·현황판에도 표시됩니다.
8. 캔디를 나눠 준 뒤 로비나 수사관 화면에서 **🏁 종료**.

## 6. 보상 규칙 (`config.json` 의 `payoff`)

팀마다 **자루는 하나**이고, 자루의 골드코인은 연출·기록용입니다.
**보상은 자루와 별개인 캔디**로, 선택 조합에 따라 정해집니다 (예전 죄수의 딜레마 앱과 같은 표, 한 번만 선택).

| 결과 | 용의자 A | 용의자 B |
|---|---|---|
| 둘 다 협력 🤐🤐 | 캔디 **3** | 캔디 **3** |
| A만 배반 🗣️🤐 | 캔디 **5** | 캔디 **0** |
| B만 배반 🤐🗣️ | 캔디 **0** | 캔디 **5** |
| 둘 다 배반 🗣️🗣️ | 캔디 **1** | 캔디 **1** |

`payoff`의 키는 "내 선택 + 상대 선택"입니다: `CC`(둘 다 협력) 3, `CD`(나는 협력·상대 배반) 0, `DC`(나는 배반·상대 협력) 5, `DD`(둘 다 배반) 1.

- 체포하는 순간의 보상표가 그 팀에 고정됩니다. `config.json`을 바꾼 뒤에는 서버를 다시 켜야 새 팀부터 적용돼요.
- 조사실 화면에는 "둘 다 입 다물면 캔디 3개 / 나만 불면 5개…" 표가 나옵니다 (`showRulesToSuspect: false`로 숨길 수 있음).

## 7. `config.json` 설정

| 항목 | 기본값 | 설명 |
|---|---|---|
| `adminPin` | `"1234"` | **운영자 PIN. 축제 전에 꼭 바꾸세요!** 환경변수 `ADMIN_PIN`이 있으면 그 값이 우선 |
| `port` | `3000` | 서버 포트 |
| `publicUrl` | `""` | QR에 넣을 주소를 직접 정하고 싶을 때 (예: `"http://192.168.0.12:3000"`). 비우면 자동 |
| `defaultCoins` | `20` | 체포 창에 미리 채워지는 자루 코인 수 (기록용) |
| `escapeTimeLimitSec` | `180` | 방탈출 타이머가 빨갛게 바뀌는 시간(초). "회장님 귀가까지 1분!" 힌트 타이밍용 |
| `defaultSessionSec` | `480` | 현황판 예상 대기 시간에 쓰는 기본 한 판 길이(초, 8분). 끝난 판이 쌓이면 그 평균으로 바뀜 |
| `parallelSessions` | `1` | 동시에 몇 판을 돌릴지 (대기 시간 계산용). 실제로 더 많이 돌아가고 있으면 그 수를 씀 |
| `payoff` | `CC 3 / CD 0 / DC 5 / DD 1` | 선택 조합별 캔디 (6장 참고) |
| `revealPartnerChoice` | `true` | 판결 때 용의자에게 동료의 선택·캔디도 보여줄지 |
| `showRulesToSuspect` | `true` | 조사실 화면에 보상표를 보여줄지 |
| `openingMessage` | 형사 첫 대사 | 심문 시작 때 자동으로 보내는 대사 (비우면 안 보냄) |
| `pressureLines` | 10개 | 수사관 화면의 압박 대사 버튼 목록 (자유롭게 추가/수정) |
| `cleanupHours` | `6` | 종료된 세션은 이 시간이 지나면 목록에서 자동 삭제 (진행 중 세션은 12시간 방치 시). 누적 통계는 남음 |

설정을 바꾸면 서버를 껐다 켜세요 (`Ctrl + C` → `npm start`). 진행 중인 데이터는 유지됩니다.

## 8. 실수했을 때 (로비 → 세션 카드의 ⚙️ 관리)

- **단계 강제 변경**: 아무 단계로 이동 (판결은 두 명 모두 선택한 뒤에만)
- **코인 수정**: 판결 전까지 자루 코인 수 수정
- **선택 다시 받기**: 두 사람의 선택과 판결을 지우고 다시 심문 (통계에서도 이전 결과 제거)
- **처음부터 (대기열로)**: 채팅·선택·코인 모두 지우고 대기열 맨 앞으로
- **삭제**
- 조사실 코드 옆 **기기 해제**: 조사실 기기를 바꿔야 할 때. 해제 후 새 기기에 같은 코드를 입력하면 이어서 진행
- 로비의 **누적 통계 초기화**: 리허설 후 실제 시작 전에 한 번 눌러 주세요

## 9. 새로고침·끊김

- 조사실 태블릿, 운영진 화면 모두 **새로고침하거나 와이파이가 잠깐 끊겨도** 자동으로 이어집니다 (기기에 저장된 열쇠 사용).
- 운영진 화면은 PIN을 한 번 넣으면 그 기기에서 기억합니다. 다른 사람에게 기기를 넘길 땐 **로그아웃**.
- 다른 기기가 이미 쓰고 있는 조사실 코드는 입력해도 들어가지지 않습니다 (가로채기 방지). 1분에 8번 넘게 틀리면 잠깐 막힙니다.

## 10. 와이파이가 안 될 때 (핫스팟)

학교 와이파이는 **기기끼리 통신을 막는 경우**가 많습니다. 다른 기기에서 주소가 안 열리면:

1. 운영진 폰 하나로 **개인용 핫스팟**을 켭니다.
2. 노트북과 모든 태블릿/폰을 그 핫스팟에 연결합니다.
3. 서버를 껐다 켜서(`npm start`) 새로 나온 `http://172.20.x.x:3000` 같은 주소를 씁니다.
   (QR은 자동으로 새 주소로 바뀝니다. 이미 연 화면은 새 주소로 다시 열어야 해요.)

인터넷이 없어도 핫스팟 안에서는 잘 동작합니다 (데이터도 거의 안 씀).

## 11. 태블릿 팁

- 아이패드: 사파리에서 주소를 열고 **공유 → 홈 화면에 추가**하면 주소창 없이 꽉 찬 화면으로 쓸 수 있어요.
- 조사실 태블릿은 **자동 잠금 '안 함'** 으로, 화면 밝기는 높게.
- **로비 매니저를 뺀 모든 화면(조사실, 잡는 사람, 수사관, 현황판, /staff)은 16:9 가로 화면에 맞춰져 있어요.**
  1280×720 ~ 1920×1080 화면에서 페이지 스크롤 없이 한 화면에 다 보이고, 글자·버튼은 화면 높이에 맞춰 커집니다.
- 로비 매니저는 가로·세로 모두 됩니다 (노트북, 세로 태블릿, 폰).

**무료 플랜 주의점**
- 15분 동안 아무 접속이 없으면 서버가 **잠들고**, 다음 접속 때 깨어나는 데 **30~60초** 걸려요. 부스 열기 몇 분 전에 현황판을 띄워 두세요 (화면이 켜져 있으면 계속 깨어 있어요).
- 서버가 **재시작되거나 새로 배포되면 진행 중인 세션·채팅·누적 통계가 초기화될 수 있어요** (무료 플랜은 파일이 보존되지 않음). 축제 당일 통계를 꼭 남겨야 하면 노트북 방식(1~3장)을 쓰세요.
- `config.json`을 바꾸려면 GitHub 저장소(https://github.com/thdtmddn/vault-heist)의 파일을 고치면 자동으로 다시 배포돼요.
